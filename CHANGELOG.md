# SynclairQGC release notes

## 0.7.1 — planned

For DigiView 0.7.1. Planned packages: Linux AppImage and Windows installer.

- Pixel (**T**) and GNSS (**Y**) tracking use the camera under the pointer and select that view when tracking starts.
- Pixel tracking can switch targets without first clearing the displayed view.
- Locking and clearing targets preserve saved manual view and stabilization settings.
- Tracking can be cleared while DigiView holds the last view after target loss.
- Stabilization uses the shared Full, Pilot, Roll and None modes, with unchanged settings preserved by partial commands.

Package builds and device validation are pending. This entry does not announce a published release.

See [published SynclairVision releases](https://github.com/SynclairVision/qgroundcontrol/releases) for downloads
and [upstream QGroundControl releases](https://github.com/mavlink/qgroundcontrol/releases)
for the base application.
